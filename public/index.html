      Architecture: Advanced Database Management System (ADBMS)

      End-to-end resume intelligence pipeline integrating NoSQL, Graph, Star Schema Warehouse, and Data Mining.

      1. MongoDB & In-Memory Mongomock

      Stores candidate JSON documents and job definitions. Executes compound indexes, multi-key array indexing on skills, and an aggregation pipeline calculating ATS scores via `$setIntersection` and weighted formula.

      2. Neo4j Graph Database

      Models relationships: (:Candidate)-[:HAS_SKILL]->(:Skill)<-[:REQUIRES]-(:Job) and skill co-occurrence (:Skill)-[:CO_OCCURS]->(:Skill) for rapid skill gap detection and recommendation.

      3. Star Schema Data Warehouse

      ETL transforms MongoDB documents into SQLite star schema with fact_application and dimensions (dim_candidate, dim_job, dim_date, dim_education, dim_skill) for OLAP roll-up and drill-down queries.

      4. Data Mining & Machine Learning

      Runs K-Means clustering (3 profile segments), Decision Tree classifier (identifying skill match as primary driver of hiring), and Association Rules (Apriori-style pattern mining).
